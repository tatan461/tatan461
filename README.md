## Core Competencies

- **Cloud Architecture:** Design and deployment of scalable, highly available AWS solutions.
- **Infrastructure as Code:** Terraform, reusable modules, HCL, remote-state concepts, and reproducible cloud environments.
- **Container Orchestration:** Amazon EKS, Kubernetes, Helm, Docker, and Horizontal Pod Autoscaling.
- **CI/CD and GitOps:** GitHub Actions, OpenID Connect authentication, Argo CD, and automated delivery workflows.
- **Observability:** Prometheus, Grafana, CloudWatch, metrics-driven monitoring, and operational visibility.
- **Cloud Security:** IAM least-privilege design, AWS KMS customer-managed encryption keys, mTLS, and secure automation.
- **FinOps:** EC2 rightsizing, Graviton recommendations, idle-resource detection, AWS Cost Explorer, and Compute Optimizer.
- **Serverless and AI:** Lambda, API Gateway, S3, DynamoDB, CloudFront, Amazon Bedrock, and AI workload cost telemetry.
- **Resilience:** Automated backup, disaster recovery, encryption, restore verification, and integrity-focused recovery workflows.
